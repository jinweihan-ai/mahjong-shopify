# FB 群组舆情监控框架 v0.1(草案)

监控出过单的 Facebook 麻将社群(社群渠道已被订单验证:#1048 Facebook 引荐、LADIESTHATMAHJ/PINKMAHJ 等社群码出单),每日汇报"大家在聊什么、有什么值得注意的"。

## 数据源(诚实设计——FB 无官方群组读取 API)

- **主通道:群组邮件通知**。店主在 FB 把目标群组通知设为"所有帖子",通知邮件(from: facebookmail.com)进店主 Gmail;routine 经 Gmail 连接器**只读检索**近 24h 通知邮件,从中提取帖子作者/摘要/链接
- **补充通道:人工喂料**。群成员把值得看的帖子链接/截图转发到本工作群,bot 纳入当日综述
- **禁止通道(铁律)**:不做 cookie 抓取、模拟登录、绕过检测的自动化——违反平台条款且有封号风险;通知邮件覆盖不到的内容如实说"看不到",不编造

## 铁律

1. 全程只读:不发帖、不评论、不点赞、不发私信、不加群
2. 隐私边界:群组帖子内容只以摘要形式出现在飞书日报,不写入仓库、不进其他报告、不用于自动化营销;个人姓名仅在"可跟进线索"里出现且仅供人工判断
3. 线索只提示不行动:发现可接洽对象 → 提示转 BD 群/媒体线人工跟进
4. 数据源健康诚实报告:昨日通知邮件数为 0 时如实说,连续 2 天为 0 提示"订阅可能失效,请店主检查 FB 通知设置"
5. 末尾水印「📡 FB舆情 v0.1」

## 日报内容(cron 每日,短报;无料可报就两行收工)

1. **话题聚类**:昨日帖子归成 3-6 个主题,各一句概括+条数(如"新手求推荐套装 ×4""线下牌局组织 ×2")
2. **值得注意**(有才写):
   - 💰 购买意向帖(求推荐/问价/问哪买)——最直接的转化线索
   - 🏷️ Averill 或竞品(Oh My Mahjong、The Mahjong Line 等)被提及,原话摘要
   - 🤝 可接洽线索(活跃组织者/内容创作者)→ 提示转 BD/媒体线
3. **数据源健康**:昨日通知邮件 N 封,覆盖群组数
4. 周一加一段:本周话题热度环比与一句洞察(55+ 女性客群语境)

## 与其他报告的关系

- 社媒日报/周报管自有账号(IG),本报管外部社群舆情,不重叠
- 发现的线索不自动写入任何 CRM/表,只在报告里提示

## 待定项(开通前店主要做的)

- 目标群组清单:待店主提供(出过单的优先)
- FB 通知设置:店主把目标群组设为"所有帖子"通知,确认通知邮箱
- 群 chat_id 与 fire token:建群后采集/生成
- Gmail 连接器在 cron 运行中的可用性:首跑前实测,不通则回退为"人工喂料为主"并如实注明
