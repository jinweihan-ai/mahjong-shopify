# Averill 店铺经营专报框架 v1.4

每日第一份报告（~08:54，四份流量报之前）：流量报告讲"人从哪来"，本报讲"生意本身"——成交、履约、库存、站点健康；周一升级为单位经济周报。

## 日期口径

- "昨日" = 北京时间前一自然日（订单 createdAt 按 UTC 存储，换算北京时间归日）
- 周一发周报（上周一至周日 vs 再上一周），其他天发日报

## 经营常量（变更需店主确认后更新本节）

- 售价 $159.99/套；COGS $75/套；交易手续费估算 2.9% + $0.30/单
- 保本 ROAS 2.2；广告费 CNY 换算 USD 按 ÷7.2
- 正式 SKU 仅 2 个：Monet's Garden、Charleston Garden No. 8（TEST-*、(Pre-Order)、（副本）变体一律忽略，但周报提醒清理直到消失）
- 库存安全线：任一正式 SKU <40 套 🟡、<20 套 🔴（断货 = 全渠道停摆）；判线用海外仓**可售数**（见下）

## 独立站库存口径（v1.3 起换源头数：YunWMS 海外仓,经张勇 CRM 只读封装）

- 数据源：CRM 登录后 GET `/api/warehouse/inventory`（凭据在任务配置;建单/取消类 POST 一律禁用）——比 Shopify 库存多"预留/在途/不可售"细分,且是仓内实数
- 报法：每 SKU 报「可售 X（预留 Y,在途 Z）」;安全线判定用**可售数**;在途>0 时跟踪落仓（落仓即报,类比 Amazon 到仓）
- **条码映射（2026-08-28 基线,两条码英文名均为 American Mahjong Set,靠 barcode 区分）**：YB759-1 = 莫奈套装（时点:可售55/预留7/累计已发95）;YB759-2 = Charleston Garden No. 8（时点:在途 276,独立站首批备货）。映射依据是在途 276 对应 Charleston 新备货;若后续出现第三条码或数字明显对不上,如实报"映射待人工核对",不硬猜
- 对照与降级：Shopify 库存数仍拉一份;两边差异 >5 套时提一句"口径漂移,建议人工核对";CRM/海外仓查询失败时降级用 Shopify 数并注明"降级口径"
- 履约红线：PAID 且未发货（UNFULFILLED/PARTIALLY_FULFILLED）超 48 小时 → 🔴 逐单点名

## Amazon 渠道（v1.2 新增，数据源 SP-API，凭据在任务配置中）

**账户结构（2026-08 基线）**：北美联合账户，主战场 US（ATVPDKIKX0DER），全 FBA。**双品牌**：zovadros（白牌）= 莫奈套装 ASIN B0GCHWVXK9（主 SKU TB-MDBG/TB-MDGB-2KGR）+ 麻将垫；**Averill** = Charleston Garden No. 8 ASIN B0HDCQR7LD（可售 288 + 在途 288，首发主战场）。基线月销约 35 单（套装 ~$145 + 垫 ~$32）。

- **每日报**：昨日 Amazon 订单数/金额（套装与配件分列）；FBA 库存水位（主力 SKU 件数 + 在途）；Charleston 到仓进度（在途 288 落仓即报）
- **告警**：🔴 zovadros 莫奈主 SKU 可售 <30；🟡 <45；🟡 任一在售变体断货超 3 天；🔴 昨日 0 单且近 7 天日均 ≥1
- **双价风控提示**（周报每期带一句）：同货双牌双价（Amazon zovadros ~$145 vs 独立站 Averill $159.99），提醒素材差异化
- **周一单位经济**：Amazon 渠道以 Amazon 专报的 Finances 真实口径为准（套装单均到手 ≈$119.26，毛利 ≈$44），本报直接引用不再粗估；与独立站渠道并排对比
- MX/CA/BR 站已开通但无量，月度看一眼即可，日报不报

## 同构原则

日报 = 核心状态仪表盘（昨日成交/本月累计/履约状态恒显）+ 变化驱动展开（积压/触线/异常才细说）；周一 = 单位经济全景。

## 日报内容（非周一，短报 6-10 行）

1. 昨日成交：销售额 | 订单数 | AOV | 用码情况（码名×次数）| 退款（无则不提）
2. 本月累计：销售额 | 订单数（对照月度节奏）
3. 履约：待发货订单数及最老账龄；全部已发货写"✅ 无积压"
3b. Amazon 段（按上文 Amazon 渠道规则）
4. 库存：两 SKU 海外仓可售数（预留/在途括号带上;触线才展开说;Charleston 在途 276 落仓即报）
5. 站点巡检：首页 + 产品页 HTTP 状态与价格串检查；429 视为"限流放行"不告警；非 200/价格串缺失 → 🔴
6. 平稳就短，不硬凑

## 周报内容（周一，全景）

1. 周成交环比：销售额/单数/AOV/退款率
2. **单位经济（本报核心）**：周收入 − COGS − 广告费（NotFair 拉近 7 天 cost，÷7.2 换 USD）− 手续费估算 = **贡献毛利**；附每单平均毛利
3. 折扣侵蚀：各码让利合计占收入比
4. 渠道毛利视角：广告费全额记入广告渠道后，各渠道（广告/SEO/社群/社媒/邮件，取订单台账口径）单数与粗毛利
5. 库存周转：按近 4 周销速估算两 SKU 可售周数（用海外仓可售数）；Charleston 上市前置提醒（正式素材/图片仍未上线则提）
6. 运营卫生：TEST/副本变体清理提醒；异常价格变体提醒
7. 建议 ≤2 条带置信度

## 趋势图（v1.4，2026-08-31 店主批准的可视化试点）

日报与周报在文本主报之外加发 1 张图（本报共 2 条消息：文本 + 图；按需重跑同样附图）：
- **近 7 天每日 GMV 柱状图**：x=日期（MM-DD，订单按北京时间归日），y=当日销售额 USD，柱顶标注当日订单数；周一周报窗口放宽为近 14 天
- 渲染：Bash 里 `pip install matplotlib --quiet` 后 python 出图;**图内文字一律英文**（云端环境无中文字体，中文会变方框），标题 "Daily GMV (USD) · last 7 days"；主色 #2F6B4A，最后一天（昨日）柱用金色 #A5731A 高亮；约 1100×420 px、dpi≥140
- 发送：PNG 上传 POST /open-apis/im/v1/images（multipart，image_type=message）取 image_key → 发 msg_type=image，content=json.dumps({"image_key": ...})
- **降级**：图生成或发送任何环节失败不阻断——文本主报必达，末尾注明「趋势图生成失败：<原因>」

## 告警（触发才写）

- 🔴 履约：PAID 未发货 >48h（逐单：单号/金额/账龄）
- 🔴 库存 <20 / 🟡 <40（任一正式 SKU）
- 🔴 站点：首页或产品页非 200（429 除外）或页面无 "159.99" 价格串（防主题事故/误改价）
- 🟡 退款：出现任何退款（金额小也报，早期口碑期零容忍）
- 🟡 昨日 0 单且近 7 天日均 ≥1 单（销售断流观察）

## 输出格式

标题：【Averill 经营日报 YYYY-MM-DD】或【Averill 经营周报 YYYY-MM-DD（第N周）】
文本主报 1 条 + GMV 趋势图 1 张（共 2 条消息，见"趋势图"节）；文本末尾水印"📚 经营框架 v1.4"（与本文件标题版本一致，不可省略）
