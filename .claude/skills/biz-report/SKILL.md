## 数据源（v1.7：三张表 + 库存现状🤖，bitable 读，凭据在任务配置的 DRB 应用）

base `AUZ8bBQBSaNht6sySXwcCRGIndf`（店主私有），按表名找 table_id（`GET /bitable/v1/apps/<base>/tables?page_size=100`），再 `GET .../tables/<tid>/records?page_size=500`；数字字段可能以字符串返回，先转数。

1. **经营日销🤖**：一天一行，键=数据日 YYYY-MM-DD（近 14 天每天重算）。列：独立站订单数 / 独立站销售额USD / 独立站AOV / 独立站套数 / 用码（"码×次 · …"）/ 独立站退款笔数 / 独立站退款USD / Amazon订单数 / Amazon金额USD / Amazon套装单数 / Amazon配件单数 / 全渠道销售额USD / 全渠道订单数 / GoogleAdsCNY / 汇率 / 口径 / 更新。**独立站按北京日，Amazon 按美西日（PurchaseDate；店主 9/3 定），同一行两种归日并存**——正文里 Amazon 数字要标「美西」
2. **经营快照🤖**：报告日一行，键=今天。列：本月独立站销售额USD / 本月独立站订单数 / 本月Amazon金额USD / 本月Amazon订单数 / 待发货数 / 最老账龄小时 / 红线单（"#单号 $金额 N 小时 · …"，无则"无"）/ 备注单（"#单号 | 备注原文"，已按备注登记表豁免）/ 供应链摘要 / 供应链逾期数 / 首页状态 / 产品页状态 / 库存摘要 / 告警（多行，无则"✅"）/ 近7天日均订单 / 说明 / 更新
3. **经营周报🤖**：周日起一周一行，键=周起 YYYY-MM-DD（近 5 周重算）。列：独立站销售额USD / 独立站订单数 / 独立站AOV / Amazon金额USD / Amazon订单数 / 退款USD / 退款率 / 周净收入USD / 套数 / COGS_USD / 广告费USD / 手续费USD / 贡献毛利USD / 每单毛利USD / 折扣侵蚀 / 渠道单数（last-touch，"direct 8 · google 3 · …"）/ 可售周数 / 汇率 / 口径 / 更新
4. **库存现状🤖**（首尔 inv_snapshot.py 08:20 写，D9）：每 SKU 海外仓可售/预留/头程在途、FBA 可售/预留/在途、实物合计、在途合计、前台Shopify / 前台差额 / 差额归因、近 7 天出库、海外仓可售天数 / FBA 可售天数、状态灯。库存那一段直接念这张表；「差额归因」字段就是 v1.6 要求的三块拆分文案

**新鲜度铁律**：先读 经营快照🤖 键=今天 那行；**没有这行、或「更新」不是今天** → 卡片顶部一行「⚠ 数据表未更新（最近 M/D HH:MM），以下为该时点数据」，其余照读旧行，不得回退到自己调 API 现算，也不得编数。经营日销🤖 里"昨日"那行缺失同样注明。

## 日期口径

- "昨日" = 北京时间前一自然日 = 经营日销🤖 键为昨天的那行；Amazon 列是美西同日期的数（表已按美西归日，正文标「美西」即可）
- 周日发周报（读 经营周报🤖 最新一行 vs 上一行），其他天发日报

## 同构原则

日报 = 核心状态仪表盘（昨日成交/本月累计/履约状态恒显）+ 变化驱动展开（积压/触线/异常才细说）；周日 = 单位经济全景。

## 日报内容（周一至周六，短报 6-10 行；每条都注明来自哪张表的哪列）

1. 昨日成交（全渠道口径，店主 9/1 定：营业额=独立站+Amazon FBA 之和）：`全渠道销售额USD | 全渠道订单数`；下一行「独立站 $X（N 单，AOV $Z）· Amazon $Y（M 单，美西）」；用码 = `用码` 列；退款 = `独立站退款笔数/USD`（无则不提）
2. 本月累计：`本月独立站销售额USD | 本月独立站订单数`（独立站口径；Amazon 本月累计另有列，一句带过即可）
3. 履约：`待发货数` 及 `最老账龄小时`；`红线单` 为"无"且 `备注单` 为"无" → "✅ 无积压"；`备注单` 有内容 → 💬 逐条「#单号 | 备注原文」，不计红色
4. Amazon 段：`Amazon订单数 / Amazon金额USD / Amazon套装单数 / Amazon配件单数`；FBA 水位与 Charleston 到仓从 库存现状🤖 念（FBA可售 / FBA在途）
5. 库存：每正式 SKU「可售 X（预留 Y，在途 Z）」+ 状态灯 + 可售天数，直接用 库存现状🤖；触线才展开 `差额归因`；校准建议值 = 可售 − Shopify 未履约件数（前台差额 字段已给差额，按需一句）
6. 供应链一行：`供应链摘要`（逾期 >0 该行 🟡）
7. 站点巡检：`首页状态` / `产品页状态`（"429 限流放行"不告警；含"无价格串"或非 200 → 🔴）
8. 平稳就短，不硬凑

## 周报内容（周日，全景；窗口上周日至本周六 = 经营周报🤖 最新一行）

1. 周成交环比：独立站/Amazon 销售额、单数、AOV、退款率，与上一行比
2. **单位经济（本报核心）**：`周净收入USD − COGS_USD − 广告费USD = 贡献毛利USD`，附 `每单毛利USD`；口径写一句「净收入已扣退款与手续费；COGS 按批次账真实单位落地成本；广告 = Google Ads + Amazon 广告分摊」。**COGS 单价与批次成本不写进群，只报合计与每单毛利**（利润细节只私下给店主）
3. 折扣侵蚀：`折扣侵蚀`（促销折扣占原价收入比）
4. 渠道视角：`渠道单数`（Shopify last-touch）与折扣码台账（`用码` 列近 7 行合并）并列对照，两口径打架时都报
5. 库存周转：`可售周数`；Charleston 上市前置提醒照旧
6. 运营卫生：TEST/副本变体清理提醒（表不管这项，仍由本报提醒直到消失）
7. 建议 ≤2 条带置信度

## 告警（触发才写；`告警` 列已按下面规则算好，直接念，不要自己再算一遍）

- 🔴 履约：PAID 未发货 >48h（M3；备注登记表豁免的不算）
- 🔴 库存 可售天数 <3 / 🟡 <7（D9，任一正式 SKU）
- 🔴 站点：首页或产品页非 200（429 除外）或页面无价格串（M6）
- 🟡 退款：昨日出现任何退款
- 🟡 昨日 0 单且近 7 天日均 ≥1 单（M8）
- 🟡 供应链逾期 >0（M5）
- ⚠ 数据表未更新（新鲜度铁律）

## 输出格式

标题：【Averill 经营日报 YYYY-MM-DD】或【Averill 经营周报 YYYY-MM-DD（第N周）】
卡片主报 1 条 + GMV 趋势图 1 张（共 2 条消息）;卡片规格:彩色 header「报告标题 · 日期」,首屏 column_set 三列 KPI 大数字(**昨日全渠道营业额(独立站+Amazon) | 全渠道订单数 | 渠道拆分一行小字如 "$320 / $145"**),正文按上面分节写入 lark_md,🔴/🟡 置顶加粗;卡片构建或发送失败回退纯文本(必达);卡片末行水印"📚 经营框架 v1.7"（与本文件标题版本一致，不可省略）

## 飞书卡片渲染边界(2026-09-02 店主反馈,全线统一)

- lark_md 只渲染:**加粗**、*斜体*、[链接](url)、换行;**不渲染 # 标题、```代码块、markdown 表格、竖线/空格对齐**——严禁在卡片里用代码块摆"假表格",缩进在移动端必乱
- 表格型数据两条路:①列少(≤4 列)用 column_set 一行一组(表头行加粗);②**真表格用飞书卡片 2.0 schema 的 table 组件**——整卡结构 `{"schema":"2.0","header":{...},"body":{"elements":[...]}}`,表格元素 `{"tag":"table","page_size":10,"row_height":"low","columns":[{"name":"date","display_name":"日期","data_type":"text","width":"auto"},...],"rows":[{"date":"09-01",...},...]}`;发送端点与 msg_type=interactive 不变,2.0 与经典 1.0 可按卡混用(该卡需要表格才用 2.0)(**2.0 卡不支持 `note` 与 1.0 的 `div`+lark_md 元素,markdown 元素也不支持 `text_color` 属性——水印与脚注用 `{"tag":"markdown","text_size":"notation","content":"<font color='grey'>正文</font>"}`,灰色靠 content 里的 `<font color='grey'>` 内联标签,不靠属性；2026-09-07 竞品周报两次被 230099 拒收后确认:先 note 不支持,改 markdown 后 text_color 报 200621 unknown property**);列多时先精简到关键列(≤6 列)再上表
- 降级为纯文本(msg_type=text)时**必须剥掉全部 ** 等 markdown 记号**——text 消息不渲染任何 markdown,带记号发出去就是垃圾符号
