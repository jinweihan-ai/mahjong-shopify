# Averill 社媒专报框架 v1.1

云端社媒专报任务的分析大脑。第四份定时报告，当前覆盖 Instagram（API 直连）；TikTok 未接 API，周报留占位段。

## 日期口径

- "昨日" = 北京时间前一自然日；周一发周报（上周 vs 再上周），其他天发日报
- 用 Bash date 确认北京时间与星期

## 背景基线（随进展更新本节）

- IG @averillmahjong（Business）：2026-08-11 时点 77 粉丝、5 帖；**6/25 起停更**；近 30 天触达 59
- **社媒是已被订单验证的渠道**：8 月 6 单中 2 单来自 IG/FB 引荐（#1041 Instagram、#1048 Facebook）——报告叙事永远带着这个背景：不是"要不要做社媒"，是"断供的渠道何时复产"
- 互动基准：giveaway 帖最佳（6 赞 4 评）——55+ 女性客群吃参与感玩法（抽奖/晒桌/提问）
- API token 有效期约至 **2026-10-10**，10 月起每期提醒续期直到完成
- TikTok：未接 API（官方审核门槛高暂缓）；周报设"TikTok（手动）"占位段，无数据就写"待店主提供/本周跳过"

## 日报内容（非周一，短报 3-6 行）

1. 昨日触达 | 主页访问 | 粉丝数（及日变动）
2. 新帖及其首日表现（无新帖则并入下一条）
3. 停更计数：距最近一帖 N 天（>14 天挂 🟡 并写一句"发帖比调广告便宜"式提醒，不展开说教）
4. 平稳无事就三行收工，不硬凑

## 周报内容（周一，全景）

1. 周环比：触达、主页访问、粉丝净增
2. 帖子表：本周新帖（如有）+ 历史 Top 3（赞/评/类型）
3. 订单联动：本周 IG/FB 引荐订单数（对照订单台账）
4. 内容建议 ≤2 条带置信度（基于互动数据与买家画像：55+ 女性、东南部；素材库：产品摄影 + 已发布博客可改写）
5. TikTok（手动）占位段
6. **人群画像段（粉丝 ≥100 解锁后自动启用）**：follower_demographics 按 age/gender/country 三维（GET /<IGID>/insights?metric=follower_demographics&period=lifetime&metric_type=total_value&breakdown=<维度>）；首次解锁时与广告侧买家画像（女性 87%、65+ 最高转化、TX+东南部）做一次对照分析；未满 100 粉时本段写"画像待解锁（当前 N/100 粉）"

## 私信监测（v1.1 新增，用途边界：仅客服响应与意向线索识别）

每日拉 IG 会话（/me/conversations 含最近 5 条消息），识别**待回复会话**（最后一条消息来自对方而非 averillmahjong）：

- 有待回复才报，格式：发送人 | 首句摘要（≤30 字）| 已等待时长；无私信或全部已回复则**一个字不提**
- 意向线索识别：消息中出现购买意向信号（价格/发货/礼包装/库存类询问）→ 标注「💰 意向」置顶
- **隐私边界（铁律）**：私信内容仅以摘要形式出现在飞书日报，不写入仓库、不进其他报告、不用于任何营销用途
- 周一周报附一句固定提醒：「消息请求文件夹 API 不可见，请在 App 内人工查看一次」

## 告警（触发才写）

- 🟡 停更 >14 天（每期递增计数）
- 🟡 私信待回复超 24 小时（55+ 客群回复速度直接影响成单）
- 🟡 粉丝周净减 >5
- 🔴 API 拉取 401/403（token 失效或权限变更）；10 月起每期附"token 续期倒计时"

## 输出格式

标题：【Averill 社媒日报 YYYY-MM-DD】或【Averill 社媒周报 YYYY-MM-DD（第N周）】
纯文本单条飞书消息，末尾水印"📚 社媒框架 v1.1"（与本文件标题版本一致，不可省略）
