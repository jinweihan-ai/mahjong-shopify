# Averill 竞品专报框架 v1.1

第六份定时报告。数据源：公司内部竞品监控系统的只读 feed API（key 在任务配置）。核心原则：**变化才是新闻**——竞品没动作时一句"平稳"收工，别把库存清单当日报。

## 数据源须知

- Feed API 每 6 小时刷新，各源抓取间隔最长 48h——"昨日变化"实际是"上一抓取周期的变化"，措辞注意
- 一天只拉一次全量（响应几 MB，Serverless 别高频）；products 带 include_inactive=true
- 两个品类：tiles（牌，主战场）、mats（垫，配件情报，低优先级）
- 时间字段全 UTC：first_seen_at=新品判定、last_changed_at=变动判定、is_active=false=已下架
- `available=true` 不等于现货：Shopify 预售品同样是 true。凡点名的单品，必须回查 tags 与 description_text 里的 preorder / pre-sale / coming soon 字样，预售要标出发货期（2026-08-17 曾据此误报 Sweet Jojo 四款为"有货"）

## 基线（2026-08-11 全量基线报告，docs/competitor-landscape-2026-08.md）

- 266 个牌类 SKU / 17 源；**Averill $159.99 = 全场正装最低价**（次低 virora $189，行业锚点 $350，天花板 Maison Mahj $575）
- The Mahjong Line 可购率仅 47%；两家 $550+ 玩家全线无货；MFM 9 款预售中
- 周报的格局对比一律以此基线为参照系，变化幅度大时提示"基线需重跑"

## 链接铁律（v1.1，店主 2026-08-17 定）

**凡在报告里点名的具体商品，必须紧跟它的商品链接**——取 feed 的 `product_url` 字段原样输出，不缩短、不改写、不做跳转包装。店主要能直接点开看竞品页，不能只给品名。

- 格式：品名后换行给裸链接（飞书文本消息会自动识别），一款一行
- 按品牌汇总的行同样要给**代表款链接**（挑折扣最深或价格最低的那款），不能整组只给文字
- 链接来自 feed，未逐条访问验活——报告脚注注明一次即可，不必逐条声明
- 唯一豁免：整组只做数量统计、不点名任何具体单品时（如"TML 38 款全量重抓"）可不给链接

## 日报内容（非周一；有变化才逐条，无变化写"竞品盘面平稳"一行）

1. **新品**（first_seen_at 近 24h）：品牌 | 品名 | 价格 | 可购 + 链接
2. **价格与内容变动**(last_changed_at 近 24h)：有 compare_at 的标注折扣力度 + 链接；变动数量大时按品牌汇总一行，附代表款链接
3. **下架**（is_active=false 且 last_seen_at 近 24h）+ 链接
4. **价格地板监察（每天必查）**：全场正装（价格 ≥$100）最低价是否仍是我们的 $159.99 之上；出现 <$159.99 的玩家 → 🔴 即时点名 + 链接。注意区分全尺寸与 mini/旅行装两条地板线，分开报
5. mats 一句话（仅新品或 ≥25% 折扣时提）；点名单品同样给链接

## 周报内容（周一，全景）

1. 各家价格带表（源 | SKU 数 | min/中位/max | 可购率），与基线对比标 ↑↓
2. 七日新品汇总与定价意图解读——**逐款给链接**，并标主题（取商品页 tags 与文案原文，如"万圣节哥特""星座水晶""协会联名"，不推测），主题是看懂对手在切哪个送礼场景的关键
3. 折扣促销榜（折扣力度排序，重点盯 OMM / TML / Sweet Jojo / virora）；榜上单品给链接
4. 可购率变化：谁在缺货、谁补货了（对照"缺货潮"基线判断窗口是否仍在）
5. 抓取健康：last_sync_status != success 的源列出
6. 对 Averill 的含义 ≤2 条（提价窗口/预售时机/竞品动作应对），带置信度

## 告警（触发才写）

- 🔴 价格地板失守：出现 <$159.99 的正装竞品（提价窗口关闭预警）
- 🔴 头部竞品大促：OMM/TML/MFM/Sweet Jojo 任一出现 ≥25% 折扣
- 🟡 抓取健康：>30% 源 failed
- 🟡 新品潮：单日新品 ≥5 款（行业上新季信号）

## 输出格式

标题：【Averill 竞品日报 YYYY-MM-DD】或【Averill 竞品周报 YYYY-MM-DD（第N周）】
纯文本单条飞书消息，末尾水印"📚 竞品框架 v1.1"（与本文件标题版本一致，不可省略）
链接按上文"链接铁律"随单品给出；消息因此变长是预期内的，不要为了短而省链接
