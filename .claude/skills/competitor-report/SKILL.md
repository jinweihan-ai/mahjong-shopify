# Averill 竞品专报框架 v1.3

第六份定时报告。数据源：公司内部竞品监控系统的只读 feed API（key 在任务配置）。核心原则：**变化才是新闻**——竞品没动作时一句"平稳"收工，别把库存清单当日报。

> **v1.2（2026-08-31 店主定）：取消竞品日报，只保留周一竞品周报。** 定时任务仅周一触发、一律发周报；下方"日报内容"节保留为**按需重跑专用体例**（群成员 @ 机器人随时索要竞品快照时用）。原日报的"价格地板监察"迁入周报必查项 + 按需重跑必查项。

## 数据源须知

- Feed API 每 6 小时刷新，各源抓取间隔最长 48h——"昨日变化"实际是"上一抓取周期的变化"，措辞注意
- 一天只拉一次全量（响应几 MB，Serverless 别高频）；products 带 include_inactive=true
- 两个品类：tiles（牌，主战场）、mats（垫，配件情报，低优先级）
- 时间字段全 UTC：first_seen_at=新品判定、last_changed_at=变动判定、is_active=false=已下架
- **落地页链接（v1.1 店主要求）**：日报的每条点名条目（新品/价格变动/新下架/价格地板触发品）与周报的所有逐品条目（Top 榜、点名清单）末尾都要附该产品的落地页 URL——取 feed 记录的产品页链接字段（url/product_url/link 之类,以实际返回为准；相对路径则拼上所属店铺域名）。链接单独占行首缩进或直接跟在条目尾,保证飞书文本消息里可点。汇总统计行（计数/均价）不用附

## 基线（2026-08-11 全量基线报告，docs/competitor-landscape-2026-08.md）

- 266 个牌类 SKU / 17 源；**Averill $159.99 = 全场正装最低价**（次低 virora $189，行业锚点 $350，天花板 Maison Mahj $575）
- The Mahjong Line 可购率仅 47%；两家 $550+ 玩家全线无货；MFM 9 款预售中
- 周报的格局对比一律以此基线为参照系，变化幅度大时提示"基线需重跑"

## 日报内容（v1.2 起仅按需重跑时使用；有变化才逐条，无变化写"竞品盘面平稳"一行）

1. **新品**（first_seen_at 近 24h）：品牌 | 品名 | 价格 | 可购
2. **价格与内容变动**(last_changed_at 近 24h)：有 compare_at 的标注折扣力度；变动数量大时按品牌汇总一行
3. **下架**（is_active=false 且 last_seen_at 近 24h）
4. **价格地板监察（周报与按需重跑必查）**：全场正装（价格 ≥$100）最低价是否仍是我们的 $159.99 之上；出现 <$159.99 的玩家 → 🔴 即时点名
5. mats 一句话（仅新品或 ≥25% 折扣时提）

## 周报内容（周一，全景；v1.2 起为唯一定时产出）

0. **价格地板监察（必查首项）**：同日报第 4 条口径；失守即 🔴 置顶
1. 各家价格带表（源 | SKU 数 | min/中位/max | 可购率），与基线对比标 ↑↓
2. 七日新品汇总与定价意图解读
3. 折扣促销榜（折扣力度排序，重点盯 OMM / TML / Sweet Jojo / virora）
4. 可购率变化：谁在缺货、谁补货了（对照"缺货潮"基线判断窗口是否仍在）
5. 抓取健康：last_sync_status != success 的源列出
6. 对 Averill 的含义 ≤2 条（提价窗口/预售时机/竞品动作应对），带置信度

## 周报可视化（v1.3，2026-08-31 店主批准的试点）

周报共 3 条消息，顺序：①文本主报 ②价格带卡片表格 ③价格分布图。按需重跑日报仍 1 条纯文本。
- **价格带卡片**（周报内容第 1 项的表格搬进卡片；文本主报里该项只留基线对比结论与 ↑↓ 点名）：经典 interactive 卡片，蓝 header「🏁 竞品价格带 · YYYY-MM-DD」；column_set 五列：源 | SKU数 | Min | 中位 | Max·可购%；行=活跃牌类源按 SKU 数降序取前 12，其余合并一行「Others」；源名截断 ≤14 字符防换行错位；每列内容为多行文本、行序全列一致
- **价格分布图**：matplotlib 水平散点条——y=各源（按中位价排序），x=价格 USD，点=该源活跃正装 SKU（price_min≥100）单价；x=159.99 处红色虚线标注 "Averill $159.99"；标题 "Full-set price landscape (USD)"；**图内文字一律英文**（云端无中文字体）；约 1200×800 px、dpi≥140；主色 #2F6B4A。渲染前 `pip install matplotlib --quiet`；PNG 上传 POST /open-apis/im/v1/images（multipart，image_type=message）取 image_key 后以 msg_type=image 发送
- **降级**：卡片或图任何环节失败不阻断——文本主报必达，末尾注明失败项

## 告警（触发才写）

- 🔴 价格地板失守：出现 <$159.99 的正装竞品（提价窗口关闭预警）
- 🔴 头部竞品大促：OMM/TML/MFM/Sweet Jojo 任一出现 ≥25% 折扣
- 🟡 抓取健康：>30% 源 failed
- 🟡 新品潮：单日新品 ≥5 款（行业上新季信号）

## 输出格式

标题：【Averill 竞品周报 YYYY-MM-DD（第N周）】；按需重跑为【Averill 竞品日报 YYYY-MM-DD（按需重跑）】
周报=文本主报+卡片+图共 3 条（见"周报可视化"节）；按需日报=纯文本 1 条；文本末尾水印"📚 竞品框架 v1.3"（与本文件标题版本一致，不可省略）
