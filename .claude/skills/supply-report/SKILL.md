# Averill 供应链专报框架 v1.1

第八份定时报告。数据源：飞书多维表《麻将批次任务拆解》（bitable API，应用凭据在任务配置）。核心方法：把甘特表当 DAG 算——关键路径、并行审计、延误传播、倒排预警。

## 数据与依赖图

- 表：app_token 在任务配置，table tblNPFT2P36NzX9l；**两轴模型（2026-08-24 迁移）**：任务名="批次前缀·对象·工序"（如 B3·礼盒·大货、B4·整批·头程运输；前缀 B1-B5 防关联选择器同名混淆）；字段：批次（=项目）/ 对象（BOM 轴：麻将牌/礼盒/麻将包/桌垫/整批）/ 工序（生命周期轴：设计→打样→大货→到厂运输→工厂打包→头程运输→上架销售）/ **计划开始·计划结束·实际开始·实际结束**（四列分离）/ 状态 / 备注 / 前置任务（依赖图第一数据源）。"模块"列已废弃勿用。批次×对象×工序 = 天然唯一键
- **计划 vs 实际分析**：延误 = 实际结束 − 计划结束；任务只有计划无实际且计划结束已过 → 逾期；日报/周报延误传播一律基于四列口径。注：历史已完成行的计划列按惯例回填为实际值（原计划未记录），此类行延误恒为 0，不参与延误统计
- **依赖推导规则**（前置任务列为空时兜底，两轴表述）：同对象内 打样←设计、大货←打样、到厂运输←大货；整批·工厂打包←麻将牌·大货+各物料·到厂运输；整批·头程运输←整批·工厂打包（无打包节点则←各对象·大货）；整批·上架销售←整批·头程运输。新任务漏填前置或漏选对象/工序 → 周报点名补填
- **以"前置任务"列为准**，推导规则仅在新任务未填依赖时兜底，并在周报提示补填

## 基线（2026-08-24 农舍批次复盘结论，长期引用）

- 农舍（Charleston）实际 9/9 开售 vs 理论最优 7/20——**串行浪费 51 天**：设计定稿（5/5）后礼盒设计晚启动 29 天、麻将包设计晚启动 40 天；三条物料链工期几乎等长（50-54 天），本可完全藏进麻将链影子里零增时
- 组织教训：**设计定稿 = 所有物料线的发令枪**，礼盒/麻将包设计必须当天启动
- 第五批 BFCM 风险：预测 11/24 开售 vs 黑五 11/27，仅 3 天缓冲

## 日报内容（非周一，短报 4-8 行；无事项时"供应链平稳"一行）

1. **逾期任务**：结束日期已过但状态非已完成 → 逐条点名（任务|批次|逾期天数）
2. **3 天内到期任务**：提醒清单
3. **开售倒计时**：农舍 9/9 / 珠光莫奈 10/8 / 秋冬 11/24（日期随表格更新）
4. 表格新鲜度：全表最后编辑距今 >7 天 → 🟡"排期表 7 天未更新，数据可能失真"

## 周报内容（周一，全景）

1. 各进行中批次关键路径与最新开售日预测（延误传播重算：任一任务实际滑动 → 沿 DAG 推下游）
2. **并行审计**：无依赖却串行执行的任务对，量化浪费天数
3. **倒排预警**：从目标开售日反推各任务最晚启动日，1 周内到点的列出；第五批 BFCM 缓冲天数每周必报
4. 新批次/新任务变更摘要（对比上周快照，快照存 /tmp 不持久也可对比当周数据结论）
5. 建议 ≤2 条带置信度

## 告警（触发才写）

- 🔴 任一任务逾期 >3 天且状态未更新
- 🔴 开售日预测因延误传播而滑动（写明"因 X 任务滑 N 天 → 开售顺延至 Y"）
- 🔴 第五批 BFCM 缓冲 ≤0 天（错过黑五）
- 🟡 排期表 >7 天无编辑

## 输出格式

标题：【Averill 供应链日报 YYYY-MM-DD】或【Averill 供应链周报 YYYY-MM-DD（第N周）】
纯文本单条飞书消息，末尾水印"📚 供应链框架 v1.1"（与本文件标题版本一致，不可省略）
