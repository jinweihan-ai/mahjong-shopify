# Google Ads 账户诊断与整改实操

**内部培训材料 · 基于 Averill Mahjong 美国站真实案例（2026 年 7 月）**

---

## 一、案例背景

- **业务**：Shopify 独立站，销售美式麻将套装，客单价 $159.99（约 ¥1,150），在售 SKU 2 个
- **账户**：币种 CNY，时区上海，投放目标美国；2 个系列（1 个搜索 + 1 个标准购物）
- **诊断范围**：近 30 天数据

**诊断前账户表面数据 vs 真实数据：**

| 指标 | 报表显示 | 真实情况 |
|---|---|---|
| 转化次数 | 51 次 | **7 笔购买** |
| 转化价值 | ¥53,880 | **¥6,804** |
| ROAS（按转化价值算） | 约 4.9 | **0.62（亏损）** |

同一个账户，同一段时间。为什么差 7 倍？这就是本材料要讲的核心内容：**报表会骗人，先校准度量衡，再谈优化。**

---

## 二、问题一：转化目标污染（本案最大问题）

### 现象

搜索系列 30 天报告 48 个"转化"，实际购买只有 6 笔。

### 根源

账户把**加购（Add To Cart）、发起结账（Begin Checkout）、购买（Purchase）三个事件都设成了"主要转化"**。三者都被计入"转化次数"，都参与智能出价。

### 为什么这是致命的

智能出价（尽量争取转化）只优化你告诉它的目标。当加购也算转化时：

1. 加购比购买容易 6 倍以上（37 次加购 vs 6 次购买）
2. 算法自然去买"容易产生加购的流量"——爱逛爱收藏但不付款的人群
3. 账面转化成本很好看，真实获客成本 ¥1,373/单，超过了客单价

### 修法

只保留 **Purchase 为主要转化（参与竞价）**，加购/结账降为"仅观察"（保留数据用于漏斗分析，不进出价）。

> **原理一句话：智能出价是一条狗，你扔什么它捡什么。扔飞盘它捡飞盘，扔加购它捡加购。**

### 自查方法（接手任何电商账户第一件事）

工具与转化设置 → 转化目标：逐个看哪些动作是"主要"。凡是加购、注册、浏览类动作被设为主要且参与竞价的，都是污染。

## 三、问题二："转化价值虚高"的侦探过程

### 现象

6 笔购买对应 ¥50,791 转化价值——单均 ¥8,465，是客单价的 7 倍。第一反应：价值追踪坏了？币种换算错了？

### 侦探过程（重要的是方法）

不要凭总数下结论，**把数据按"转化动作 × 日期"拆开**：

```
逐日拆分后：
  Purchase：   每笔 ¥867–1,084  ← 正常！就是单笔订单金额
  Add To Cart：每次带 ¥1,084    ← 元凶：每次加购都携带整单价值
  37 次加购 × ¥1,084 ≈ ¥40,100 + 结账 ¥4,757 + 购买 ¥6,804 ≈ ¥51,700 ✓ 对账成功
```

结论：购买价值追踪本身**没有坏**，虚高完全来自问题一（加购/结账的价值被算进总数）。修好问题一，这个问题自动消失，**不需要动 Shopify 侧的任何配置**。

> **教训：看到异常总数，先拆分（按动作、按天、按系列），对上账再动手。差点白折腾一场 Shopify 排查。**

## 四、问题三：出价策略与数据量不匹配

### 现象

购物系列用"尽量争取点击"（无 CPC 上限），实际 CPC 高达 ¥16.3——是搜索系列（¥6.5）的 2.5 倍，展示份额 85%（在无脑赢下所有竞价），30 天只换来 1 笔购买（¥2,695/单）。

### 原理：出价策略的选择由"喂给它的数据量"决定

| 该系列月真实转化量 | 合理策略 |
|---|---|
| 0–15 | 手动 CPC / 带上限的尽量点击 |
| 15–30 | 尽量争取转化 |
| 30+ 稳定 | tCPA（目标设在近 30 天实际值附近） |
| 有可信的转化价值回传 | tROAS |

月购买 1 笔的系列上任何智能出价都是"无米之炊"——所以本案**没有**直接换"尽量转化"，而是先用 **¥4 CPC 上限**止血，等量起来再升级。

### 附带修复

- 关闭搜索合作伙伴网络（默认开启，流量质量差，新账户先关）
- 排除 Charleston 产品：它的商品图还是另一款的占位图，图不符 + ¥271 零转化。**Feed 素材没准备好的商品不要投**

## 五、问题四：零否定关键词

账户跑了一个月，否定词数量：**0**。搜索词报告里在烧钱的：

| 垃圾类型 | 实例 | 为什么烧钱 |
|---|---|---|
| 渠道错位 | mahjong set **costco** | 用户要去 Costco 买，不会来独立站 |
| 品类错位 | **travel** mahjong set / **christmas** tiles | 我们不卖旅行装；圣诞词 7 月无意义 |
| 研究意图 | how to play / rules / tips / strategy guide | 学规则的人，不是买家 |
| 游戏意图 | mahjong **online** / **solitaire** / free mahjong | 找网页游戏的人——麻将品类特有的大坑 |
| 无厘头 | **pickleball** mahjong | 匹配漂移 |

### 实操要点

1. **Phrase 否定的机制**：否定短语 "free mahjong" 只拦"这两个词按此顺序相邻出现"的查询，不拦单独的 "free"。想拦得宽用否定广泛（要求所有词都出现，顺序不限）。大部分"否了却没拦住/拦多了"都栽在这个机制上
2. **不要过度否定**：竞品词（sweet jojo、oh my mahjong）虽然点击不少，但**有转化迹象且数据太薄**——本案选择留着观察，而不是一刀切。否定"明确错的"，不否定"暂时不确定的"
3. **带日历的否定词**：christmas 现在是垃圾流量，Q4 是黄金流量——**否定列表要写进运营日历**（本案备忘：Q4 前移除）
4. 用**共享否定列表**挂到所有系列，而不是逐系列贴

### 每周搜索词三步清洗（固定动作）

1. **垃圾**：有花费（3+ 点击）零转化且明显不相关 → 否定
2. **金矿**：产生转化但还不是关键词的搜索词 → 加为词组/完全匹配
3. **漂移**：词组匹配拉来的邻近但错误的意思 → 收紧匹配或否定

### 实战反转：costco 否定词的撤回（本案第二大教训）

整改当天我们把 `costco` 加进了否定列表——依据是 `mahjong set costco` 8 次点击 0 转化，"用户要去 Costco 买，不会来独立站"，逻辑上无懈可击。

**两天后按转化动作拆分数据复查，结论反转**：`costco mahjong` 这个搜索词用不到 ¥100 的花费产出了 1 笔购买 + 2 次加购 + 2 次发起结账——**全账户 CAC 最好的搜索词**，被我们否掉了。买家搜"costco 麻将"，看到我们的广告，直接买了。撤回否定。

三条教训：

1. **否定决策必须看"按转化动作拆分"的数据**，聚合的转化列（尤其在转化目标污染期间）会同时高估垃圾词、掩盖金矿词
2. **"逻辑上显然是垃圾"不等于数据上是垃圾**——零售商词、比价词都可能截流到即刻成交的买家
3. **每一个否定词都值得在下一轮清洗时复核一次**，否定列表不是只进不出的黑名单

同一轮复查中，反向的判断也成立了：竞品品牌词整改时因"显示有转化"而留观，拆分后发现那些全是加购、30 天 0 购买，还混着 `discount code`、`warehouse sale` 这种找竞品折扣的流量——收网否定。**同一份数据，同一个方法，一个词捞回来，一批词否出去。方法比立场重要。**

## 六、问题五：质量得分与落地页——以及一次"技术正确但业务错误"的决策

### 现象

主力词 QS 只有 3–5 分；搜索展示份额 18%，其中 **64% 输在广告评级**（不是预算）。

### 原理

QS = 预期点击率 × 广告相关性 × **落地页体验**。泛词（"mahjong sets for sale"）落到单品页，查询意图（比较/挑选）和页面（单一商品）不匹配。教科书解法：泛词 → 品类集合页。

### 但是——业务现实推翻了教科书

我们当天把落地页切到了集合页，店主随即指出：**集合页里两个产品，其中一个还在用占位图**。让付费流量看到"半成品品类页"，比意图轻度不匹配的"完整单品页"伤害更大。当天改回单品页。

> **教训：优化建议要过一遍"用户真的会看到什么"。技术上正确的改动，如果落在没准备好的页面上，就是错误的改动。此项列入待办：Charleston 正式素材上线后再切集合页。**

## 七、运营纪律（本案暴露的坏习惯）

1. **投放骤停骤启**：7 月 8–18 日日花费从 ¥500+ 骤降到 ¥5–160，随后又拉回 ¥1,000。每次骤变都重置智能出价学习期（1–2 周），等于反复交学费。预算调整按 **±20% 步进，间隔 3–5 天**
2. **学习期内不动账户**：本次整改后 1–2 周是重新学习期，不动预算、不动出价、不频繁看单日数据下结论
3. **对账户动手前先留基准**：本案基准 = 30 天花费 ¥10,936 / 7 单 / 购买价值 ¥6,804 / 真实 ROAS 0.62。两周后对着这组数字验收

## 八、可复用检查清单：接手任何电商 Google Ads 账户

按顺序查，前三项没查清之前不要碰出价和预算：

- [ ] 1. 转化目标：哪些动作是"主要"？有没有加购/注册/浏览混进竞价目标？
- [ ] 2. 转化价值：单均价值 ≈ 客单价吗？异常就按"动作 × 日"拆分对账
- [ ] 3. 真实成交数：用订单后台核对，算出真实 CAC 和 ROAS
- [ ] 4. 出价策略与该系列月转化量是否匹配（对照第四节表格）
- [ ] 5. 否定关键词：有没有？搜索词报告里前 50 个词过一遍
- [ ] 6. 网络设置：搜索合作伙伴/展示网络是不是默认开着
- [ ] 7. 商品 feed：图、标题、价格与落地页一致吗？没准备好的 SKU 在投吗？
- [ ] 8. 落地页与查询意图匹配吗？页面本身完整吗？
- [ ] 9. QS 与展示份额：输在预算还是输在评级？（两种病，两种药）
- [ ] 10. 日花费曲线：有没有骤停骤启的痕迹？
- [ ] 11. 地理/币种/时区口径：报表金额是什么币种？投放地在哪？
- [ ] 12. 品牌词有没有人蹭？要不要单独建品牌系列？
